7 · Learn the geometry

Gradient: ∇f = (∂f/∂x, ∂f/∂y). It points toward the direction of steepest local increase. Its length gives the maximum rate of increase per unit distance.

The direction of steepest decrease is −∇f. If ∇f = 0, the point is stationary to first order.

For a unit direction u = (cos θ, sin θ), the directional derivative is Dᵤf = ∇f · u = fₓ cos θ + fᵧ sin θ.

0.000

The directional derivative measures the rate of change in the chosen direction.

The graph is the surface z = f(x,y). At each horizontal input (x,y), the function assigns a scalar height z. Contours are sets of points with equal function value. The gradient is perpendicular to the local level curve (when the gradient is nonzero).

The expression engine supports common real-valued functions, not arbitrary programming code. Numerical derivatives use central finite differences, so values near discontinuities, singularities, sharp cusps or very rapid oscillations may be inaccurate. The renderer draws a sampled wireframe, not an exact symbolic surface.
